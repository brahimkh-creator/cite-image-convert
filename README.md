# PixelForge AI 🛡️⚡
### أستوديو تحويل وضغط وتعديل الصور بالذكاء الاصطناعي على جهاز المستخدم 100% (Client-Side & Offline Ready)

---

## 🌟 الفكرة ونقطة الجذب التسويقية للمستهلك (Privacy-First USP)
تعتمد أغلب مواقع تحويل وضغط وتعديل الصور السحابية على **رفع صور المستخدمين الشخصية والحساسة إلى خوادمها البعيدة (Cloud Servers)**. هذا يثير مخاوف كبيرة لدى المستهلكين بشأن الخصوصية وتسريب البيانات، فضلاً عن بطء الانتظار أثناء رفع وتنزيل الملفات ووجود قيود وباقات مدفوعة.

**PixelForge AI** تم بناؤه من الصفر ليعمل **محلياً بنسبة 100% داخل متصفح المستخدم (On-Device Processing)**:
- 🔒 **أمان وخصوصية مطلقة**: لا يغادر بايت واحد جهازك إلى أي خادم خارجي (0 Bytes Uploaded).
- ⚡ **سرعة البرق**: المعالجة فورية وتستغل قوة المعالج والكرت الرسومي (CPU & GPU) لحاسوبك.
- 🌐 **يعمل بدون إنترنت (Offline Ready)**: يمكنك فصل الإنترنت بالكامل وسيستمر التطبيق في العمل بكفاءة.
- ♾️ **بلا حدود أو رسوم**: معالجة مئات الصور دفعة واحدة دون أي قيود على الحجم أو العدد.

---

## 🚀 المميزات والوظائف الرئيسية

### 1. تحويل صيغ الصور (Format Conversion)
- تحويل فوري ودقيق بين الصيغ التالية:
  - **WebP**: الجيل الأحدث والأكثر توفيراً لمواقع الويب وسرعة التحميل.
  - **PNG**: يدعم الشفافية الكاملة والجودة الخالية من أي فقدان (Lossless).
  - **JPG / JPEG**: التوافق الأقصى للصور الفوتوغرافية مع خوارزمية ضغط قياسية.
  - **AVIF**: أحدث تقنيات الضغط العالمية (توفير إضافي حتى 50% مقارنة بـ WebP).
  - **ICO**: إنشاء أيقونات المواقع (Favicon) متعددة المقاسات (16x16, 32x32, 48x48, 64x64, 128x128).
  - **BMP**: حفظ كملف نقطي (Bitmap) غير مضغوط.
  - **SVG**: تضمين متجهي متوافق مع دقة الشاشات المختلفة.

### 2. ضغط الصور الذكي (Smart Compression)
- أنماط ضغط جاهزة:
  - **أقصى توفير (Max Savings)**: تقليل الحجم حتى 85% مع ملاءمة شبكات التواصل والمواقع.
  - **متوازن (Balanced)**: التوازن الذهبي الموصى به للمواقع.
  - **جودة فائقة (High Quality)**: الحفاظ على أدق التفاصيل مع خفض الحجم الزائد.
- تحكم دقيق بمستوى الجودة (1% إلى 100%) وتغيير الأبعاد (Scale).
- **شريط المقارنة التفاعلي (Before / After Split Slider)**: فحص مباشر للفروقات بالبكسل قبل الحفظ.
- حساب حي لنسبة التوفير والحجم الأصلي والجديد وزمن التنفيذ بالمللي ثانية.

### 3. أدوات الذكاء الاصطناعي المحلية (On-Device AI Studio)
- ✂️ **عزل وإزالة الخلفية التلقائي (AI Background Removal)**:
  - كشف ذكي لحدود العنصر الرئيسي (Saliency & Edge Detection).
  - خيارات استبدال الخلفية: **شفافة تماماً**، **لون مخصص (Color Picker)**، أو **تمويه سينمائي (Blur)** للخلفية الأصلية.
- 🪄 **الممحاة السحرية الذكية (Magic Object Eraser & Inpainting)**:
  - رسم مباشر بالفرشاة فوق أي عنصر غير مرغوب به، شخص، علامة مائية، أو شوائب.
  - خوارزمية ترميم النسيج محلياً (Fast Marching / Texture Synthesis) لإعادة بناء الخلفية بسلاسة بدون سيرفر.
- 🔍 **تكبير وتحسين الدقة الفائق (AI Super-Resolution 2X / 4X)**:
  - مضاعفة دقة الصور مع تطبيق فلاتر استعادة التفاصيل الحادة (Neural Edge Sharpening).
- ✨ **التحسين التلقائي (Auto-Enhance)**:
  - توسيع النطاق الديناميكي (Dynamic Range)، ضبط التباين التلقائي، وتعزيز حيوية الألوان (Smart Vibrance).
- 🎬 **فلاتر سينمائية وذكية (Cinematic & Neural Filters)**:
  - أوضاع: *Cinematic Teal & Orange*، *Cyberpunk Neon*، *Golden Hour*، *B&W Pro*، *Vintage*، *Vivid HDR*.
- 🎚️ **تحكم يدوي احترافي بالألوان**:
  - السطوع، التباين، التشبع، والتمويه (Blur).

### 4. المعالجة الجماعية (Batch Queue & ZIP Download)
- سحب وإفلات عشرات الصور دفعة واحدة.
- دعم اللصق المباشر من الحافظة بالضغط على `Ctrl+V`.
- تطبيق إعدادات الصيغة والجودة على كافة الصور بنقرة زر واحدة.
- شريط تقدم مباشر (Progress Bar) للمعالجة المتسلسلة.
- تحميل كافة الصور المعالجة في أرشيف مضغوط واحد `ZIP` بنقرة واحدة.

## 🛠️ البنية التقنية (Tech Stack)
- **Frontend Framework**: React 19 + TypeScript + Vite 6
- **Styling**: Tailwind CSS + Cairo Typography (Google Fonts) + Dark/Light Theme + Full RTL / LTR Toggle
- **Image Processing**: HTML5 Canvas, OffscreenCanvas, ImageData ArrayBuffer, Custom BMP/ICO Binary Encoders
- **Local Inpainting & AI Engine**: Fast Marching Synthesis, Saliency Detection, Convolution Unsharp Masking
- **Archiving**: JSZip
- **Icons**: Lucide React
